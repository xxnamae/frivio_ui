# Frivio UI

Frivios designsystem, pakket som en agent-skill: tokens, primitiver (kit), regler og eksempler
som gjør at en kodeagent bygger «rett og rolig» norsk verktøy-UI på første forsøk.

- Levende showcase: <https://design.frivio.no>
- Spesifikasjonen (maskinlesbar, offentlig): <https://www.frivio.no/design.md>
- Installer i et prosjekt: `npx skills add xxnamae/frivio_ui`

Innholdet i `skills/frivio-ui/` er et speil av `skill/frivio-ui/` i Frivios hovedrepo og
publiseres av `scripts/publiser-skill.sh` der. Rediger aldri her; endringer gjøres i kilden.
